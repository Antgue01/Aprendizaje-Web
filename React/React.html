React

React crea Single Page Applications (SPA). Un único `index.html` se carga y su contenido se actualiza dinámicamente en el navegador. Visualmente parece que navegas, pero lógicamente, todo ocurre en la misma página, sin recargas completas.

El principio de diseño ideal en React es que cada elemento o sección de la página sea un componente distinto, fomentando la modularidad y reutilización, por lo que el archivo index.html de una aplicación React contiene un único <div> con un id="root" (o similar), donde todo el contenido de la aplicación se inyecta y gestiona mediante JavaScript.

Utiliza JSX, una sintaxis desarrollada para React que "permite" escribir HTML dentro de JavaScript, lo que facilita la creación de componentes y su estructura visual. JSX se transpila (compilar de un lenguaje a otro) JavaScript puro antes de ejecutarse en el navegador.

Beneficios

React funciona a través de node.js (permite simular un servidor en local) y una serie de programas:

npx @react-native-community/cli init NombreDeTuApp
¡Copiado!

Descarga y configura React Native dede la plantilla de la comunidad, preparada ya con React y los proyectos de Android e iOS.

npm install [paquete]
¡Copiado!

Instala un paquete específico o todas las dependencias listadas en package.json en el directorio del proyecto.

yarn install [paquete]
¡Copiado!

Lo mismo pero mejora mejor las dependencias porque busca las más actualizadas que no entran en conflicto.

npm start
¡Copiado!

Ejecuta el script de inicio definido en package.json, que típicamente despliega la aplicación en un servidor de desarrollo local para visualización.

npm run build
¡Copiado!

Compila para producción, optimizando y minimizando los archivos (CSS, JS, etc.) y eliminando código no utilizado. Genera una versión lista para ser desplegada.

Importante para la resolución de problemas

Si encuentras errores al compilar (build) o tras actualizar versiones, es una buena práctica eliminar node_modules y package-lock.json antes de ejecutar un nuevo npm install. Esto asegura una instalación limpia de las dependencias.

npm install -g serve
¡Copiado!

Instala globalmente el paquete serve, un servidor web estático ligero para probar la build. El flag -g lo hace disponible en cualquier directorio del sistema.

serve -s build
¡Copiado!

Inicia el servidor serve, sirviendo el contenido de la carpeta build (la versión compilada de tu aplicación) de forma estática.

Set Up

La página se configura en el index.js, donde se importan tanto los componentes y los CSS como los módulos que sirven para crear y enrutar (asignar página a "url") los componentes de la aplicación.

import React from 'react'; import ReactDOM from 'react-dom'; import App from './components/App'; // O './App' si App.js está en la raíz import 'bootstrap/dist/css/bootstrap.min.css'; import HomePage from './pages/HomePage';
¡Copiado!

Después, enrutamos la aplicación,es decir, asignamos las URL a páginas de nuestra web de forma que cuando se escriba una URL nuestra, React sepa que tiene que reconfigurar el DOM (o la View en native).

Finalmente, creamos el root y renderizamos. Para ello, llamamos a ReactDOM.createRoot(div con id "root") y a su método render(componentes).

const root = ReactDOM.createRoot(document.getElementById('root')); root.render( <React.StrictMode> <App /> </React.StrictMode> );
¡Copiado!

La palabra clave class se reemplaza por className para evitar conflictos con JS.
