Elementor

Elementor es un potente constructor visual de páginas para WordPress, pero es importante considerar su rendimiento. [cite_start]Puede ser hasta 3 veces más lento que un WordPress nativo debido a la carga de sus propios estilos y scripts[cite: 1]. Muchas de sus funcionalidades se pueden replicar o incluso mejorar con plugins externos más ligeros y específicos.

Consejos y Funcionalidades

WordPress

Custom Post Type UI (CPTUI)

El plugin Custom Post Type UI (CPTUI) en WordPress es fundamental para extender la funcionalidad de tu sitio. [cite_start]Sirve para crear tipos de contenido personalizados más allá de los tradicionales "Posts" y "Páginas"[cite: 5]. Piensa en ellos como "estructuras" de datos personalizadas.

Funcionalidad y Uso

  • [cite_start]Su principal utilidad es permitirte rellenar una base de datos con campos específicos que añades para cada tipo de contenido[cite: 6].

WP Coder y Carga de Librerías/Scripts

[cite_start]Para cargar librerías y scripts externos en WordPress, plugins como WP Coder ofrecen una interfaz sencilla en el apartado Scripts & Styles[cite: 9].

Si no utilizas un plugin específico para esto, la práctica común es insertar el código directamente en los archivos del tema activo. Los lugares más comunes son:

Archivos del Tema para Scripts

  • Theme Header (header.php): Para scripts que deben cargarse al principio.
  • Theme Footer (footer.php): Ideal para scripts que no bloquean la renderización del contenido, justo antes del cierre de la etiqueta </body>.
    • [cite_start]
  • Functions.php: El lugar preferido para registrar y encolar scripts y estilos de forma correcta usando las funciones de WordPress (wp_enqueue_script() y wp_enqueue_style())[cite: 10].

GeneratePress

La plantilla GeneratePress es altamente optimizada para la personalización y el rendimiento. [cite_start]Viene con su propio plugin (GeneratePress Premium) que, al configurarlo, permite activar distintos módulos para añadir funcionalidades[cite: 12].

Características Clave

  • [cite_start]Estos elementos permiten una inclusión condicional, lo que significa que puedes elegir exactamente dónde quieres que aparezcan (por ejemplo, solo en páginas específicas, entradas de un tipo determinado, o para ciertos roles de usuario)[cite: 15].

Temas Hijos (Child Themes)

La práctica estándar en WordPress es utilizar temas hijos. [cite_start]Un tema hijo hereda la funcionalidad y el estilo de un tema padre, pero te permite realizar modificaciones sin alterar los archivos del tema original[cite: 16]. Esto es crucial porque si modificas el tema padre directamente, tus cambios se perderán cada vez que el tema se actualice. El tema hijo se sube después del tema padre.

Instalación y Creación

  • [cite_start]Para instalar plantillas de HTML o temas en WordPress, ve a Apariencia -> Temas y haz clic en Añadir Tema[cite: 11].
  • A menudo, las plantillas premium o los temas más complejos requieren la instalación manual de plugins asociados. [cite_start]Generalmente, una vez instalado el tema, verás una notificación o una sección dentro del tema para instalar estos plugins de forma masiva (bulk install)[cite: 17, 18].
  • [cite_start]Para crear un tema hijo de forma sencilla, puedes utilizar plugins como WP Child Theme Generator[cite: 21]. Este plugin automatiza el proceso de crear los archivos necesarios para tu tema hijo.

Resetear el Sitio de WordPress

En ocasiones, necesitas resetear tu instalación de WordPress a un estado limpio, por ejemplo, para empezar un nuevo proyecto o deshacer muchos cambios.
